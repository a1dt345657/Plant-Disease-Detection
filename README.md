# Plant-Disease-Detection
An AI/ML-based Plant Disease Detection system using deep learning, EfficientNet, and image processing to identify plant diseases from leaf images. Uses data augmentation and self-supervised learning to improve model performance.


## 🌱 Plant Disease Detection Using Deep Learning

This project focuses on detecting plant diseases by analyzing images of plant leaves using deep learning and computer vision techniques.

### Key Features

* **Deep Learning:** Uses EfficientNet and transfer learning for image classification.
* **Data Augmentation:** Applies image transformations and CycleGAN-generated images to improve dataset diversity.
* **Self-Supervised Learning:** Uses a SimCLR-inspired framework to learn useful image representations.
* **Model Evaluation:** Uses confusion matrices and Grad-CAM visualizations to evaluate model predictions and understand model attention.
* **Disease Knowledge Base:** Provides additional information about predicted plant diseases.

### Technologies Used

Python, TensorFlow/Keras, EfficientNet, Computer Vision, Deep Learning, and Jupyter Notebook.
